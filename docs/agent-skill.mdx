Lumbridge TUI ships a reusable agent skill file at [`skills/lumbridge-tui/SKILL.md`](../skills/lumbridge-tui/SKILL.md).

Install that file into any coding agent that supports reusable skills or custom instructions. The skill teaches the agent how to control Lumbridge TUI from inside a Lumbridge TUI pane.

## What the skill does

The skill tells an agent to use the `lumbridge-tui` CLI when `LUMBRIDGE_TUI_ENV=1` is set. That means the agent is running inside a Lumbridge-managed pane and can safely talk to the local Lumbridge TUI socket.

With the skill installed, an agent can:

- inspect workspaces, tabs, panes, and neighboring agents
- split panes and run commands without stealing focus
- read pane output and recent logs
- wait for servers, tests, or another agent to finish
- start helper agents in sibling panes

The skill is a Markdown instruction file for agents. If Lumbridge TUI is already installed, run `lumbridge-tui --skill` to print the release-matched copy bundled with that binary.

## Install it

Print the copy that matches your binary and save it where your agent reads
skills, for example for Claude Code:

```bash
mkdir -p ~/.claude/skills/lumbridge-tui
lumbridge-tui --skill > ~/.claude/skills/lumbridge-tui/SKILL.md
```

The source of truth is `skills/lumbridge-tui/SKILL.md` in this repository.

For agents with a skill system, install that file as a skill named `lumbridge-tui`. For agents without a skill system, paste the file into the agent's project or user instructions.

After installation, start the agent inside Lumbridge TUI:

```bash
lumbridge-tui
claude
```

Or use any other coding agent in a Lumbridge TUI pane so `LUMBRIDGE_TUI_ENV=1` is available to the agent process.

## Safety rule

The skill starts with one guardrail: if `LUMBRIDGE_TUI_ENV=1` is not set, the agent should stop and say it is not running inside a Lumbridge-managed pane.

This prevents an agent outside Lumbridge TUI from trying to control a session it does not own.
